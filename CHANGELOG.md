# Changelog

## 2.0.1

- Added a five-case long-form self-review with source, first-pass and final text; every source/final exceeds 200 whitespace-delimited words.
- Clarified local negation and pronoun-reference checks after paragraph restructuring.
- Clarified that narrative editing must not add events or feelings unless creative expansion is requested.
- Recorded actual first-pass defects and their corrections without presenting self-review as independent evaluation.

## 2.0.0

- Rewrote the instruction contract with selectable tone, address, task, editing strength, length and output modes.
- Separated editing source text from writing a reply to it; added context-aware support and web-copy guidance.
- Added explicit checks for local qualifications, speaker roles and structured text preservation.
- Removed private-user context from the public prompt package.
- Added bilingual documentation, attribution, examples, 18 development cases, 4 fresh holdout cases and optional dependency-free validation utilities.
- Recorded evaluation scope and limitations separately from package validation.

## 1.0.0

Initial local instruction-only version: context-selected register, Persian orthography, fidelity checks and website-orchestrator routing. It was not a public benchmarked release.
